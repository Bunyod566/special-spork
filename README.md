# EduFlow

Fayllar:
- index.html  — asosiy sayt
- admin.html  — admin panel (alohida sayt)

## VS Code da ishga tushirish
1. VS Code da `File > Open Folder` orqali shu papkani oching.
2. `Extensions` dan "Live Server" (Ritwick Dey) ni o'rnating.
3. `index.html` ustida o'ng tugma > "Open with Live Server".
   Admin uchun `admin.html` ni xuddi shunday oching.

## Firebase (ixtiyoriy)
`index.html` va `admin.html` ichida `FIREBASE_CONFIG` ni toping va
`YOUR_...` o'rniga Firebase Console > Project settings > Web app kalitlarini qo'ying.
Ikkala faylda ham bir xil kalit bo'lishi kerak. Qo'ymasangiz, sayt lokal rejimda ishlaydi.
